# DevOps Responsibilities

## Cloud Infrastructure

- Worked with Google Cloud infrastructure supporting the application platform.
- Managed containerized workloads on Cloud Run.
- Supported Cloud SQL / PostgreSQL connectivity.
- Worked with load balancing and application traffic.
- Managed/support Cloud Storage resources.
- Worked with Cloud Armor / WAF protection.

## Containerization

- Built and worked with Docker-based application containers.
- Managed container images through Artifact Registry.
- Supported Cloud Run deployments and revisions.

## Operations

- Reviewed application and infrastructure logs.
- Troubleshot deployment, runtime, connectivity, and availability issues.
- Performed post-deployment validation.
- Supported recovery using known-good application revisions.

## Security

- Worked with Cloud Armor / WAF-protected traffic.
- Avoided exposing credentials and confidential infrastructure information.

## Important

This document describes the responsibilities represented in this project documentation. Exact internal service names, project IDs, IP addresses, credentials, tokens, and confidential configuration are intentionally omitted.
