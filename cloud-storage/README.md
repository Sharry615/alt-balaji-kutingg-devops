# Cloud Storage

Cloud Storage was used as the object/file storage layer for platform workloads.

## DevOps Work

- Managed cloud storage resources used by application workloads
- Supported file/object operations
- Investigated application access to storage resources
- Troubleshot storage-related application issues
- Reviewed access and configuration requirements

## Storage Flow

```text
Application
    |
    v
Cloud Storage
    |
    v
Objects / Files
```

Sensitive bucket names, credentials, and production object paths are intentionally excluded.
