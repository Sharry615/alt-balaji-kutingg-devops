# Cloud Armor / WAF

Cloud Armor provided the web application firewall and edge protection layer.

## DevOps Work

- Worked with WAF-protected application traffic
- Investigated blocked or rejected requests
- Reviewed security-related traffic behavior
- Supported rule/configuration troubleshooting
- Correlated security behavior with application availability

## Traffic Flow

```text
Internet
   |
   v
Load Balancer
   |
   v
Cloud Armor / WAF
   |
   v
Cloud Run
```

## Security Focus

- Malicious/request filtering
- Application-layer protection
- Traffic inspection
- Rule troubleshooting
- Availability impact analysis
