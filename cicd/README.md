# CI/CD and Container Delivery

The platform used a container-based delivery workflow.

## Deployment Flow

```text
Source Code
    |
    v
CI/CD Process
    |
    v
Docker Image
    |
    v
Artifact Registry
    |
    v
Cloud Run
```

## DevOps Work

- Supported container image build and delivery
- Worked with Docker-based application packaging
- Managed container images in Artifact Registry
- Supported deployment to Cloud Run
- Validated deployed revisions
- Investigated deployment and runtime failures

Exact internal pipeline names, repository details, credentials, and deployment secrets are intentionally excluded.
