# Google Cloud Load Balancer

The Google Cloud Load Balancer provided the external traffic entry point for the application platform.

## DevOps Work

- Worked with load-balanced application traffic
- Supported routing between the external endpoint and application services
- Troubleshot application reachability through the load balancer
- Investigated backend/service health issues
- Supported SSL/TLS and domain-based application access

## Traffic Flow

```text
Client
  |
  v
Load Balancer
  |
  v
Security Layer
  |
  v
Cloud Run
```

## Operational Checks

- Frontend reachability
- Backend/service health
- Routing
- SSL/TLS
- DNS/domain access
